## 왜 만들었나요

아이들은 블록을 쌓고 무너뜨리며 놀 기회가 예전보다 적습니다. 여러 모양의 블록을 쌓고 쓰러뜨려 보면서 공간 감각과 구조의 안정성을 자연스럽게 익히도록 만들었습니다.

*Children have fewer chances to play with physical blocks. This app lets them stack and topple blocks of many shapes to build a feel for space and structural stability.*

## 기능

- **블록 11종:** 테트리스에서 영감을 받은 모양으로 자유롭게 구조 만들기
- **현실적인 물리 반응:** SpriteKit 물리 엔진의 중력·충돌
- **무너짐도 놀이로:** 쓰러지는 과정을 보며 다시 쌓아 보기
- **실물 놀이로 이어지기:** 화면 속 경험이 실제 블록 놀이의 계기가 되도록

## 기술

Swift · SpriteKit · iPadOS 전용
